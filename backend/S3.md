# Optional S3

S3 multipart upload lives in [`optional/s3storage`](optional/s3storage/) as a **separate Go module**.

- Default backend (`cmd/server`) uses local disk only — no AWS dependencies in the root `go.mod`.
- To enable S3 in your own app, import `optional/s3storage` and pass it as `upload.Options.Storage`.
- To remove S3 entirely, delete the `optional/s3storage` directory.
